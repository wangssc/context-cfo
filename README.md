# context-cfo 🧾 你的 AI 到底在烧多少钱？

> 一个纯 Python 标准库的 skill，扫描你的 agent 配置目录，把 token 开销算成一张**能拿给老板看的账单**。

## 它解决什么问题

你的 AI 每次回答都要把一堆 skill、mcp 配置、说明文件塞进上下文。这些东西**每一轮都在烧钱**，但你不知道：

- 每次加载到底多少 token？占上下文窗口多少？
- 一次会话多少钱？**一个月烧多少钱？**
- 哪个文件最烧钱？能不能删？
- 哪些能砍、能省多少、哪些**碰都不能碰**？

现存工具都在教你「少说点话」，没人把这件事**算成一张账单**。

`context-cfo` 就是那张账单。

## 一句话看懂

```bash
python scripts/estimate.py ~/.workbuddy/skills --sessions-per-month 500
```

输出长这样：

```
========================================================================
AI 上下文成本账单
========================================================================

一句话结论：
  最烧钱的是 skills/long-doc/说明.md，占总量约 49%。
  每次加载约 2120~3027 token，成本 0.0212~0.0303 元。

【1 总量】文件 5 个 · 窗口占用 1.3%
【2 构成】按文件从大到小排好
【3 成本】单次 + 月度投影
【4 可砍量】指向死重清单
```

## 四个能力

| 能力 | 回答的问题 |
|------|-----------|
| 总量 | 每次加载多少 token，占上下文窗口百分之几 |
| 成本 | 一次会话多少钱，一个月烧多少钱（月度投影） |
| 构成 | 哪个文件最烧钱，从大到小排好 |
| 可砍清单 | 哪些能删、能省多少、哪些不许碰 |

## 为什么可信（而不是「算出一个漂亮但错的数字」）

- **分字符类型估算**：中文 0.9~1.3 token/字符，英文/代码 0.25~0.35。不混成一个系数（混了会低估中文一半以上）。
- **给区间不给单点**：每个数字带 lo~hi，误差藏不住。
- **可手算复核**：任何数字都能拿字符数按声明公式反推，`tests/bill-config-demo.txt` 留了一次完整运行的输出，可拿 `wc -m` 的字符数按公式反推。
- **只读**：不修改你的目录。
- **可砍 ≠ 已省**：绝不写「已省 X 元」，只写「可砍 X」——这是这类工具最容易被识破的谎言。
- **盲区标明**：不读使用日志，无法判断某个 skill 是否真的没用过，对这类对象只输出 `unknown`，不瞎猜。

## 风险分级（不是所有「死重」都能删）

- 🟢 **低**：背景叙述、重复规则——可删可压缩。
- 🟡 **中**：触发条件模糊的 skill——删了可能少一个能力，需人工确认。
- 🔴 **高**：安全/合规硬约束——**不许删，只能压缩措辞**。

## 为什么是纯标准库

一个帮你审计成本的工具，自己带一堆依赖，说服力就没了。零依赖、不联网、Python 3.8+ 直接跑。

## 快速开始

```bash
# 算账单（含月度投影）
python scripts/estimate.py <你的配置目录> --sessions-per-month 500

# 找死重 + 可砍金额
python scripts/audit.py <你的配置目录> --sessions-per-month 500

# 指定模型单价（价格会变，别写死）
python scripts/estimate.py <目录> --price-per-1m 3 --context-window 1000000
```

## 目录结构

```
context-cfo/
├── SKILL.md              # 可安装入口
├── scripts/
│   ├── estimate.py       # 采集 + 换算 + 账单
│   └── audit.py          # 死重判定 + 可砍金额
├── demo/                 # 自造样本（扁平放，平台不允许三级目录）
├── references/           # 换算依据、死重判据
├── tests/                # 一次运行的账单留档
└── DESIGN-NOTES.md       # 设计判断与推翻
```

## 什么时候别用

- 没有配置目录时。
- 只问单个文件多大时——`wc -c` 就够了。
- 要精确到真实 tokenizer 逐字对照时——本工具只给区间，不给假精度。
